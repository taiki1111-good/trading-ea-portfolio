# exp_006_overextension_reversion_notes

## 仮説
短時間で価格が一方向に伸びすぎた局面では、その後に一部の引き戻し（平均回帰）が発生する可能性がある。

ただし本仮説は、初期段階で逆張りエントリー戦略として直接採用することを目的としない。まずは、追随エントリーの見送り条件、exit補助、risk縮小の補助判断として検証する。

## exp_004_failure_reversal_notes.md との違い
- `exp_004` は false breakout / trap / failed breakout のような「失敗確定後の逆走拡大」仮説を扱う。
- `exp_006` は失敗パターン確定を前提にせず、「短時間の過伸長そのもの」に対する引き戻し・平均回帰仮説を扱う。
- `exp_004` は主に失敗構造検知の精度が中心で、`exp_006` は過伸長判定とその後の戻りの発生傾向が中心となる。

## 成立条件
- 短時間での価格変動が「行き過ぎ」とみなせる候補条件を満たすこと。
- 行き過ぎ判定後、一定時間内に反対方向への引き戻しが観測されること。
- 引き戻しがノイズではなく、見送り/exit補助/risk縮小の判断改善に寄与すること。

「行き過ぎ」の定義は未確定とし、以下を将来検証候補とする。
- ATR正規化（短時間変動幅のATR比）
- 直近 n 本の値幅・伸長速度
- MA乖離
- HTF/SR 近接との組み合わせ
- 急騰急落後の失速（ローソク形状・連続性の鈍化）

## 否定条件
- 強トレンド継続局面で、行き過ぎ後も順方向へ素直に伸び続ける場合。
- 行き過ぎ判定の閾値依存が強く、期間や銘柄で再現性が低い場合。
- 引き戻しが観測されても、実運用上の判断改善（見送り/exit補助/risk縮小）に寄与しない場合。

## 主な用途
- 追随エントリーの見送り条件（過伸長局面での新規追随を抑制）
- 保有ポジションの exit 補助（利確/縮小/建値保護の補助判定）
- リスク縮小（ロット抑制、保守側SL/TP調整の判断補助）

逆張りエントリー戦略としての採用は最終段階の比較対象とし、初期検証の優先対象にはしない。

## 評価指標
- 行き過ぎ判定後の一定時間内における引き戻し発生率
- 引き戻し幅の分布（raw値 / ATR正規化）
- 見送り条件として使った場合の誤見送り率とドローダウン抑制寄与
- exit補助として使った場合の平均保有時間・平均損益・最大逆行抑制
- risk縮小として使った場合の損失側テール抑制（大損回避寄与）

## 比較対象
- 過伸長判定を使わない現行ベースライン
- 過伸長判定を「見送り条件」のみに使う構成
- 過伸長判定を「exit補助」のみに使う構成
- 過伸長判定を「risk縮小」のみに使う構成
- 参考比較として、`exp_004` の失敗確定ベース逆走拡大仮説

## 採用判断基準
- 複数期間・複数条件で再現性があり、短期サンプル依存が過度でないこと。
- 見送り/exit補助/risk縮小のいずれかで、ベースラインに対して一貫した改善傾向があること。
- 過剰最適化（閾値の後付け最適化）に依存していないこと。
- ニュース・指標時の異常値だけで成立していないこと。
- main 導入時に既存責務（Signal / RiskFilter / BacktestRunner / PipelineAdapter）を不必要に複雑化しないこと。

## 非対応範囲
- 本メモは実験仮説の文書化のみであり、main ロジックへの即時導入は行わない。
- 逆張りエントリー戦略の本採用は対象外（最終段階の候補比較に留める）。
- Signal / RiskFilter / BacktestRunner / PipelineAdapter の実装変更は行わない。
- 収益性確認済み、実運用準備完了、live readiness を主張しない。
