# exp_004_failure_reversal_notes

## 仮説
執行足におけるブレイクや第三波進行が短時間で否定された場合、いわゆる false breakout / trap / failed breakout に近い失敗パターンが成立し、その後の逆走拡大局面を捉えることができると仮定する。

本体の既存ロジックに即時採用するのではなく、まずは `experiments` 領域で「失敗検知」「失敗確定」「逆走拡大化」を比較検証する対象とする。

## 成立条件
- 執行足でブレイクまたは第三波進行が一時的に成立したこと
- 直後の短時間内に当該ブレイク/進行が明確に否定されたこと
- 失敗パターンが false breakout / trap / failed breakout に近い構造として判定できること

## 否定条件
- ブレイク/第三波進行が十分な余地を残して継続した場合
- 否定が曖昧で、逆走拡大に至るかどうかが不明瞭な場合
- 方向判断に頼らず、単なるノイズ逆行と判断される場合

## 評価指標
- 失敗検知後の逆走拡大ケースにおける実現損益
- 逆走拡大局面での平均リスクリワード
- 失敗検知の精度（真陽性 / 偽陽性）
- 見送り条件・停止条件として使った場合の誤停止率
- 逆張り戦略として使う前に、見送り/停止条件としての安全性と有効性

## 比較対象
- 通常の stop hit ケース
- 失敗確定後の逆走拡大ケース
- 失敗検知を経由せずに従来ロジックだけで取引を継続した場合

## 採用判断基準
- 逆走拡大局面を十分に高い精度で分離できるか
- 見送り・停止条件として導入した場合、誤停止が受容範囲内か
- 逆張り戦略として使う前に、現行ロジックの安全性を低下させないか
- 実験結果が本体ロジックを改善する傾向を示すか
- 失敗検知器の追加が本体の設計品質を著しく悪化させないか
