# 概要

## プロジェクト名
Trading EA

## プロジェクト概要
本プロジェクトは、モジュール分割と段階的テストを前提として、自動売買EAを設計・実装する個人開発プロジェクトである。

単に売買ルールを作るのではなく、データ処理、上位足環境認識、執行足構造認識、シグナル判定、リスク管理、実行管理、記録、評価という流れを分離し、保守性・説明可能性・拡張性を意識した構成を目指す。

## 背景
自動売買システムは、売買条件そのものだけでなく、データの扱い、状態管理、リスク制御、ログ記録、テスト設計によって品質が大きく左右される。

そのため、本プロジェクトでは、EAを単なる売買ルールの集合としてではなく、ソフトウェア工学的に設計されたシステムとして扱う。

## 目的
- EAを構造化された形で設計する
- 上流モジュールから順に実装する
- 各段階でテストを挟みながら開発する
- 後から改善しやすい構成にする
- ポートフォリオとして説明しやすい形に整理する

## 想定する全体像
本プロジェクトでは、以下の流れで処理を行うことを想定している。

Data -> HTFContext -> LTFStructure -> Signal -> RiskFilter -> Execution -> Logger -> Evaluator

詳細な責務分離は `docs/03_architecture.md` と `docs/04_module_spec.md` を正とする。

## 初期段階の対象
初期段階の main では、執行足構造として `third_wave_break` を優先対象とする。

`triangle_break` は、初期段階では `experiments` 領域で先行検証し、本体への導入は後段で判断する。
